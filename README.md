# Lista de Tarefas (To-Do List)

## Sobre o projeto

Uma aplicação web para criar e gerenciar uma lista de tarefas.

O usuário poderá adicionar tarefas, marcá-las como concluídas e removê-las. A ideia é transformar uma lista simples em uma aplicação interativa utilizando JavaScript.

## Objetivo

Praticar JavaScript desenvolvendo uma aplicação que manipule elementos da página dinamicamente e mantenha os dados das tarefas salvos no navegador.

## O que pretendo colocar

* [ ] Campo para adicionar uma tarefa
* [ ] Botão para adicionar tarefa
* [ ] Exibição das tarefas
* [ ] Marcar tarefa como concluída
* [ ] Remover tarefa
* [ ] Editar tarefa
* [ ] Contador de tarefas
* [ ] Filtro de tarefas
* [ ] Botão para limpar tarefas concluídas

## Funcionamento planejado

1. O usuário escreve uma tarefa.
2. O JavaScript captura o texto.
3. Uma nova tarefa é criada e adicionada à lista.
4. O usuário pode marcar a tarefa como concluída.
5. O usuário pode editar ou remover a tarefa.
6. As tarefas são armazenadas no `localStorage`.
7. Ao recarregar a página, as tarefas são recuperadas.
8. O usuário pode filtrar as tarefas por status.
